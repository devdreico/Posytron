# Posytron

POS SaaS multi-país (LATAM) y multi-vertical. El comerciante compra su cuenta dentro del software y opera todo su negocio —sucursales, cajas y verticales— desde un solo panel.

**Diferenciador:** IA que responde el negocio en lenguaje natural.

## Documentación

- [Plan de implementación v1](docs/PLAN-IMPLEMENTACION.md)

## Stack

- **Web:** React 19 + Vite + TypeScript + Tailwind
- **Móvil:** Expo (React Native)
- **API:** FastAPI + SQLModel
- **DB:** PostgreSQL 16 (multi-tenant con RLS)
- **Infra:** Docker Compose
